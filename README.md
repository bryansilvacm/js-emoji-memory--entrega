JOGO DA MEMÓRIA COM EMOJIS 

Mais um Desafio da DIO do bootcamp Ri Happy - Front-end do Zero #2

A idéia desse projeto é um jogo da memória com emojis, onde trabalhamos estrturas de decisão, arrays, laço de repetição, entre outras estruturas. Nesse jogo o jogador deve se desafiar a encontrar os pares de emojis que são embalharados de forma aleatória e automática pelo JS, para ficar mais emocionante desenvolvi um timer para cronometrar o tempo gasto pelo usuário para vencer o jogo, podendo assim se desafiar a vencer cada vez em menos tempo

Clique [aqui](https://bryansilvacm.github.io/js-emoji-memory--entrega/) para acessar o jogo e se divertir!

Tecnologias Utilizadas:
- HTML;
- CSS;
- JAVASCRIPT
